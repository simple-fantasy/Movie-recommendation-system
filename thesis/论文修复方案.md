---

## 修复原则

1. **一次只改一处** — 每一步修改单一目标，改完、验证、确认后再进入下一步
2. **可回滚** — 每一步前创建备份，出问题可回到上一步
3. **追踪修改** — 所有docx编辑使用 tracked changes（修订模式），方便人工審阅
4. **人可检查** — 每一步输出 before/after 对比，清晰标记变更内容
5. **禁止脚本批改** — 不写Python批量修改docx；使用 unpack → 手工 Edit XML → pack 流程

**目标**: 解决0.8148 vs 0.6954的矛盾——在修改论文前，先确定哪个值是正确的

**背景**: `ncf_v2_meta.json` 中不包含验证指标记录。需要从训练日志或其他来源确定正确值。

```bash
# （查看shell历史或日志目录）

# 3. 如无日志，从 ncf_v2_meta.json 提取训练配置，确认验证时的采样参数
python -c "
import json
with open('backend/artifacts/ncf_v2_meta.json') as f:
    meta = json.load(f)
print('config:', json.dumps(meta.get('config',{}), indent=2))
print()
print('Available keys:', list(meta.keys()))
train = meta.get('train', {})
if train:
    print('train keys:', list(train.keys()) if isinstance(train, dict) else type(train))
```

**决策点**（需人工判断）:

**产出**: 一个确定的、可验证的验证集NDCG@10值

每步均支持独立回滚：

