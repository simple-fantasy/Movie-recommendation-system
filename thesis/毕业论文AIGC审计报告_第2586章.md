## 三、第5章 AIGC 审计

### 3.1 AI模式识别

第5章整体AIGC风险低。已在前次降重中修复了5.5.1节的教科式开头。剩余问题：

**模式1: 批大小讨论的教科式陈述** (5.5.2)

> "批大小（batch size）是影响训练效率的关键因素之一。批大小过小会导致每次计算规模不足，GPU无法充分利用并行计算资源（或在CPU上导致框架调度开销占比上升）；批大小适当增大可以提升单次计算的吞吐，使计算资源利用率提高并缩短单位epoch耗时。然而，批大小过大也可能带来显存压力（GPU模式）或影响优化过程的收敛特性，需要结合模型规模与硬件条件进行权衡。"

| AI特征 | 说明 |
|--------|------|
| "是影响...的关键因素之一" | AI定义引导句 |
| "批大小过小...批大小适当增大...然而批大小过大..." | 教科书三段对比 |

## 五、第8章 AIGC 审计

### 5.1 AI模式识别

第8章是全文中AIGC风险最高的章节。**不是因为内容像AI——而是因为操作手册本身就是模板化文体。**

**模式1: 操作步骤模板** (全文)

每个小节使用完全相同的结构：
```
标题: 功能名称
  → 描述句: "用户通过...可完成..."
  → 操作步骤: "访问...进入...点击...查看..."
  → 截图: [图8-X]
```

这种结构在第8章中重复了**20+次**（对应20+张截图）。

**模式2: 引导式描述** (8.1 普通用户使用指南)

> "访问系统首先进入门户首页，展示系统简介与'立即开始'入口按钮。点击进入登录注册页面：新用户填写用户名和密码并确认后完成注册并自动登录；已有账户直接输入凭据登录。"

| AI特征 | 说明 |
|--------|------|
| "访问...进入...点击..." | 操作手册的标准语序 |
| 每句都以动词开头 | AI偏好祈使/引导语气 |
| "遗忘密码时可使用密保问题验证身份后重置密码" | 功能枚举式描述 |

**模式3: 截图+标题的机械重复** (全文)

20+张截图 = 20+段"描述→[图8-X 标题]"的重复单元。AIGC检测器对这种高度规律的结构极为敏感。

### 5.2 修复建议

| 优先级 | 操作 | 效果 | 工作量 |
|--------|------|------|--------|
| **P1** | **删除第8章**，关键截图移至第5/6章 | 一举消除80-85% AIGC | 大(需重新组织截图) |
| P1 | **压缩为附录**，2页纯文字无截图 | AIGC降至40-50% | 中 |
| P2 | 保留原文，缩短每个小节至1-2句 | AIGC降至60-70% | 小 |

**推荐P1方案A（删除第8章）**：
- 第8章20+张截图中约5张（推荐页面、用户画像、数据看板、评估对比）可移至第5/6章作为实现/验证的展示
- 剩余操作指南截图删除
- 第1章"八章"→"七章"

### 5.3 预估降幅

- 方案A: 80-85% → **0%**（章节不存在）
- 方案B: 80-85% → **40-50%**
- 方案C: 80-85% → **60-70%**
