## 一、AI痕迹逐章审计

### 第1章 绪论

#### 1.1 研究背景 (风险: 中)

**AI模式**: 空洞行业描述 + 无引用断言

> "电影推荐是推荐系统领域的经典应用场景。Netflix、IMDb等平台拥有数十万部电影资源，传统的排行榜和编辑推荐方式难以兼顾用户的个体兴趣与长尾内容的曝光。"

| 问题 | 类型 |
|------|------|
| "Netflix、IMDb等平台" | 模糊举例(AI常用套路) |
| "数十万部" | 不精确数字(AI偏好概数) |
| "传统...难以..." | AI对比套路(传统X vs 现代Y) |

**修复方向**: 删除或替换为具体引用。如改为"MovieLens 32M数据集中87,000部电影的评分密度仅0.14%，用户-物品交互矩阵高度稀疏"——用论文自己的数据说话。

---

> "协同过滤算法能够直接利用用户-物品交互信息挖掘相似性，是推荐系统中应用最广泛的经典方法之一。其中，基于物品的协同过滤（Item-based Collaborative Filtering，ItemCF）由于具备较好的可解释性、工程实现简单、在线计算效率高等特点，常被用于推荐候选集召回。"

| 问题 | 类型 |
|------|------|
| "应用最广泛的经典方法之一" | AI万能定语(无引用支撑) |
| "具备较好的" | 模糊定性(什么叫"较好"?数字?) |
| "工程实现简单、在线计算效率高等特点" | 三段式排比 |
| "常被用于" | 模糊归因(谁在用?有无引用?) |

**修复方向**: 删除"应用最广泛的...之一"和"常被用于"。改为直接陈述ItemCF在本系统中的角色。

---

> "然而，协同过滤方法在表示能力上存在上限，难以充分刻画复杂的非线性偏好关系。深度学习推荐模型通过Embedding与神经网络结构增强了特征表达能力，在排序精度方面表现突出，但其训练与推理成本相对较高，更适合用于候选集的精排或重排阶段。因此，'召回-重排'的两阶段混合推荐框架在工业界被广泛采用。"

| 问题 | 类型 |
|------|------|
| "在表示能力上存在上限" | AI模糊缺点描述 |
| "增强了特征表达能力" | 宣传式(AI偏好"增强""提升") |
| "在排序精度方面表现突出" | 无数据支撑的断言 |
| "因此...在工业界被广泛采用" | 伪因果 + 模糊归因 |

**修复方向**: 删除"工业界被广泛采用"。改为"这种召回-重排架构在本文中被采用，具体为ItemCF召回+NCF重排"——聚焦本系统的选择理由。

#### 1.2 研究意义 (风险: 低-中)

**(2) 工程实践意义**:

> "形成覆盖数据管理、离线训练、在线服务和可视化分析的工程链路"

**问题**: 工整的四段式排比("数据管理、离线训练、在线服务和可视化分析")

**(3) 应用价值**:

> "可作为推荐算法对比实验和工程教学的实践平台"

**问题**: 此前已降级但仍偏宣传。建议改为"为离线推荐算法对比提供了本地可运行环境"。

#### 1.3 国内外研究现状 (风险: 中高)

**这是全文中AI痕迹最集中的区域**。典型AI文献综述模式:

**模式1: 堆叠式综述** (AI将文献按时间/主题堆叠, 不做真正的综合)

> "在相似度计算方面，常见方法包括余弦相似度、皮尔逊相关系数、Jaccard系数等[1,3]。针对评分数据，研究者通常会引入评分归一化、惩罚热门物品、时间衰减等机制..."

| 问题 |
|------|
| "常见方法包括...等" — AI枚举模式 |
| "研究者通常会引入" — 模糊归因, 无具体研究者 |
| "评分归一化、惩罚热门物品、时间衰减等" — 三段式枚举 |

**模式2: AI对比句式重复使用**

该节使用了3次"相较于X，Y在...方面更..."的AI对比模板:
1. "相较于UserCF，ItemCF在...往往具有更好的..."
2. "相较于传统CF，NCF在表达能力方面更强"
3. (隐含对比) "在隐式反馈场景中取得较好的排序效果"

**模式3: AI万能适用性断言**

> "因此非常适合用于资源受限但希望获得更好效果的推荐系统实现"

| 问题 | AI模式 |
|------|--------|
| "非常适合用于" | AI万能适用性断言 |
| "资源受限但希望获得更好效果" | 模糊场景描述(谁?什么资源?) |

**修复方向**: 整节重写为"技术选择理由"而非"文献综述"。本科论文不需要综述30篇文献——需要解释**为什么选择ItemCF和NCF**。每个技术选择的理由来自本项目的数据特征和工程约束。

**模式4: 模板式研究缺口**

> "需要结合具体数据与场景进行系统化设计与实验验证。"

这是AI论文标准结尾——"需要进一步研究"的变体。
