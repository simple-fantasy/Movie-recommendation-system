1. **论文是 Markdown→pandoc 转的 docx，不是原生 Word** — 正文用 Times New Roman、表格原是制表符段落、无 TOC 字段。现在表格已转真Word表，但字体和TOC仍需手动在Word中修复。

2. **表6-1 数据来自 evaluation_results.json** — 是唯一真实来源。不要从任何其他地方复制数字。

3. **NCF v2 参数来自 ncf_v2_meta.json** — embedding_dim=64, hidden_dim=256, neg_ratio=4, epochs=20。

4. **draw.io CLI 有已知 bug** — `rounded=1 + fontStyle=1 + value` 组合会导致渲染崩溃。改用 matplotlib 生成架构图/时序图，仅用例图使用 draw.io（用 ellipse 形状避免触发 bug）。

5. **论文标题的"融合"论证** — 消融实验发现 recall_k=50 时 Hybrid 超越纯 ItemCF，为标题提供了证据支撑。答辩时强调架构融合而非单点性能最优。

6. **不要删除公式修复时改动过的 XML 结构** — 公式(2-1)(2-2)已修复为 center+italic，后续补充 (2-3)~(2-8) 时复制此结构。
