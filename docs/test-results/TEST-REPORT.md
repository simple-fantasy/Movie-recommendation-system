## 三、推荐引擎专项验证

### 3.1 策略可用性

| 场景 | Popular | ItemCF | NCF | Hybrid |
|------|---------|--------|-----|--------|
| 匿名用户 | ✓ 热门推荐 | ✓ 回退热门 | ✓ 回退热门 | ✓ 回退热门 |
| 已登录无评分 | ✓ 热门推荐 | ✓ 回退热门 | ✓ 回退热门 | ✓ 回退热门 |
| 已登录有评分 | ✓ | ✓ 基于相似度 | ✓ 用户不在集回退ItemCF | ✓ ItemCF召回+NCF重排 |
| NCF模型未就绪 | ✓ | ✓ | ✓ 自动回退ItemCF | ✓ 自动回退ItemCF |

### 3.2 冷启动处理

所有 4 种策略对匿名用户和无评分用户均正确返回热门推荐作为兜底方案，并在 response meta 中标记 `cold_start: true` 和 `fallback: "cold_start"`。

### 3.3 回退链验证

NCF 策略回退链: `用户不在训练集 → ItemCF回退 → 无ItemCF数据 → Popular兜底` — 全部链路正常。
